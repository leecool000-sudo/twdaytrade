# 處置候選股推播（明日再注意即處置）

每天收盤後抓證交所＋櫃買中心近 30 個營業日的注意股紀錄，找出**明天只要再被列注意一次就會進處置**的個股，推播到 Discord。

## 判斷邏輯

| 處置條件 | 差一天的狀態（今天收盤後） |
|---|---|
| 連續 3 日 第一款 | 今天、昨天都是第一款 |
| 連續 5 日 第一～八款 | 已連續 4 日被列注意 |
| 10 日內 6 次 | 最近 9 日（含今天）已 5 次 |
| 30 日內 12 次 | 最近 29 日（含今天）已 11 次 |

- 款次直接從公告文字裡的「第X款」讀取；當沖占比那款不計入。
- 排除已在處置中的股票和今天剛公告處置的股票；最近一次處置公告日之前的注意次數不再累計（實際資料驗證：冠西電 10/29 處置後重新計數，11/3 再次處置）。
- 只看 4 碼普通股。要納入 ETF，改 `STOCK_CODE_RE`。

### 價格欄位（用官方個股日成交資料）
- **6日**：官方的「累積漲跌幅」是**每日漲跌幅加總**，不是複利（已用 11/13 公告數字驗證）。
- **明日漲跌 ≥ X% 即達第一款**：明天的 6 日累積 = 最近 5 日加總 + 明天漲跌幅，以 32% 門檻估算。X 在漲停內，代表明天再拉一根就會觸發「連 3 日第一款」。
- 🔺近60日高點、距20日高：判斷是否在相對高點。
- 📉跌幅觸發：因跌幅達第一款而上榜的股票，型態跟「隔天拉高」不同，另外標記。

> 估算只用 6 日 32% 這條；第一款另有 25%＋價差、30／60／90 日等條件，週轉率、本益比等其他款也可能讓股票上榜，所以「漲停也到不了」不代表明天不會被列注意。

### TradingView
- Discord 訊息裡的股號是連結，點了直接開 TradingView 線圖（上市 `TWSE:`、上櫃 `TPEX:`）。
- 每天推播最後一則會附上 `tradingview_YYYYMMDD.txt`，同時存一份在 `output/`。
  匯入方式：TradingView 右側觀察清單 → 清單名稱旁的選單 →「匯入清單…」→ 選這個檔案。

## 安裝

1. Discord 頻道 → 編輯頻道 → 整合 → Webhook → 新增 → 複製網址。
2. 本機測試：
   ```bash
   pip install -r requirements.txt
   python tw_disposal_watch.py --date 2026-11-13 --dry-run     # 只印不推
   export DISCORD_WEBHOOK_URL="https://discord.com/api/webhooks/..."
   python tw_disposal_watch.py
   ```

## 自動排程（GitHub Actions，免費）
1. 把這個資料夾推到一個 GitHub repo（建議 private）。
2. Repo → Settings → Secrets and variables → Actions → 新增 `DISCORD_WEBHOOK_URL`。
3. 預設台北時間週一到週五 18:07 自動執行；Actions 頁面也能手動執行並指定日期。
4. 遇到假日，程式會自己判斷不是交易日然後結束。

如果 GitHub 的海外 IP 被證交所擋，改用 Windows 工作排程器或 macOS cron 在自己電腦上跑同一個指令。

## 參數
- `--date YYYY-MM-DD`：回測指定日期
- `--dry-run`：不推 Discord
- `--no-price`：不抓價格（比較快）
- `--json out.json`：另存結果
