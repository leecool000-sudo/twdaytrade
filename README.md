# 台股當沖多代理人系統(紙上交易版)

把「GROKBOT + JEV」的分工改成台股現股當沖。**只有紙上交易**,`LiveBroker` 刻意留空。

## 角色對照

| 影片角色 | 本系統 | 檔案 | 用 LLM? |
|---|---|---|---|
| CRAWLER | 行情(證交所MIS)、處置/注意股名單、新聞標題 | `crawler.py` | 否 |
| SCAN | 開盤區間突破 + 量比 + VWAP + 漲幅 打分數 | `agents.py` ScanAgent | 否 |
| VET | 處置/注意/黑名單、價差、跳動單位占比、近漲停、流動性、未放量 → 任一項否決 | VetAgent | 否 |
| SOCIAL | 新聞標題 → Claude 判斷利多/利空(沒設金鑰就中性) | SocialAgent | **是(可選)** |
| SIZE | 依單筆風險、單檔上限、扣成本後報酬風險比算股數 | SizeAgent | 否 |
| FILLS | 紙上成交(含手續費、證交稅、滑價) | `broker.py` | 否 |
| RISK | 停損、保本、移動停利、時間停損、尾盤平倉、單日熔斷 | RiskAgent | 否 |
| CHIEF | 彙整後拍板,自己不持倉 | ChiefAgent | 否(可再加) |

原則和影片一樣:**需要判斷的放 LLM,涉及錢的全用寫死的規則。**

## 執行

```bash
pip install -r requirements.txt

python main.py --mode sim --seed 7    # 離線模擬行情,驗證流程(行情是人造的,結果不代表真實績效)
python main.py --mode live --top 60   # 開盤前啟動:證交所即時行情 + 紙上交易
# 選用:export ANTHROPIC_API_KEY=... 啟用 SOCIAL 的新聞判讀
# 選用:建立 restricted.txt,每行一個代號(券商軟體顯示「禁現沖」的股票)
```

交易明細輸出到 `out/trades_*.csv`。參數全在 `config.py`。

## 台股當沖的成本現實(務必先理解)

- 現股當沖賣出證交稅 0.15%(減半優惠,目前法規延長到 2027/12/31)+ 手續費 0.1425%×2×折扣。
  不計折扣,一來回約 0.435% 才打平。
- 升降單位:<10 元 0.01、10~50 元 0.05、50~100 元 0.1、100~500 元 0.5、500~1000 元 1、≥1000 元 5。
  股價 100~165 元附近,一檔就占 0.3~0.5%,`max_tick_pct` 會自動把這類股票擋掉。
- 預設停損 0.7%、停利 1.8%,扣完成本報酬風險比約 1.3~1.4,**勝率要超過約 45% 才有正期望值**。
  把 `slippage_ticks` 設成 1 做壓力測試,多數標的的 SIZE 會直接拒絕下單,代表這組參數對成本很敏感。

## 限制與實盤前必做

1. 目前**只做多**。現股先賣後買(沖賣)需另外處理可放空名單,未實作。
2. `TwseMisFeed` 與處置/注意股、新聞抓取需要網路,**我在沙盒中無法連線測試**,欄位與端點請在你的電腦上驗證;
   MIS 有頻率限制,輪詢間隔請 ≥5 秒。程式不處理休市日,請自行避開。
3. 模擬行情是人造的(刻意埋了真/假突破),只用於驗證流程。請用**真實歷史逐筆資料回測**,
   再紙上交易數週,看成本後是否仍有正期望值。
4. 當沖資格:開戶滿三個月、近一年成交達10筆、簽風險預告書與當日沖銷契約書;處置股、全額交割股、限制信用股不可當沖。
5. 13:25~13:30 為收盤試撮,價格不確定,所以預設 13:15 強制平倉。若未能當日沖銷,會轉成 T+2 交割並要有足額資金,有違約交割風險。
6. 接實盤前:實作 `LiveBroker`(用限價單)、處理部分成交與斷線、API 金鑰不給提款權限、保留手動平倉能力。

## 手動下單模式(Discord 通知)

系統只發訊號,不連任何券商 API。背景仍用紙上帳本追蹤「若完全照訊號」的結果。

1. Discord 建立專用頻道 → 編輯頻道 → 整合 → Webhook → 新增 Webhook → 複製網址。
2. 在 GitHub Secrets 新增 `DISCORD_WEBHOOK_URL`;想要手機推播就再加 `DISCORD_MENTION`(格式 `<@你的使用者ID>`,
   取得方式:Discord 設定 → 進階 → 開啟開發者模式 → 對自己按右鍵 → 複製使用者ID)。
   本機執行則用 `export DISCORD_WEBHOOK_URL=...`。**Webhook 網址等同密碼,不要貼到程式碼或公開處。**
3. 訊息種類:✅啟動、🟢買進訊號(限價、最高可追價、股數、停損、停利)、🟡停損上移、🔴賣出訊號、⚠️警示、📊收盤結算。
4. 每個交易日 09:00 前沒收到「✅系統啟動」,就代表排程沒跑起來,請自行處理。
5. 手動下單守則:用限價單;價格超過「最高可追價」就放棄;買進後立刻在券商設好停損觸價單;
   你沒跟單的訊號,看到對應賣出訊號時忽略即可。
6. 另外自己記錄「實際成交價 vs 系統建議價」。這個落差(手動延遲與滑價)就是將來自動化前最重要的數據。
